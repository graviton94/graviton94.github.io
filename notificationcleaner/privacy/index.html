알림 청소부 (Notification Sweeper) · 시행일: 출시일 · Effective: launch date

한국어

알림 청소부는 폰 알림을 밀어서 합치고 터뜨리는 게임이에요. 계정도 로그인도 없어요. 게임 진행은 이 폰 안에 저장되고, 아래 기능에 필요한 만큼만 폰 밖으로 나가요.

  • 폰 안에: 게임 진행(판 · 포인트 · 데이터 · 백업파일 · GB · 앱 · 프리미엄 등급 · 출석 · 업적 · 설정)은 이 폰에 저장되고, Android 기기 백업을 켜 두었다면 Google 백업에 함께 담겨요.
  • 광고: 보상형 광고(원할 때만 보는 광고)는 Google AdMob과 AdMob 미디에이션으로 연결된 광고 네트워크가 보여 주고, 광고와 측정을 위해 광고 ID · 기기 정보 · 대략적인 위치(IP)를 처리해요. 유럽 경제 지역 · 영국에서는 처음에 동의를 받아요. Google의 처리 방식: policies.google.com/technologies/partner-sites
  • 사용 통계: 연쇄 · 레벨 업 · 초기화 · 광고 시청 · 출석 · 구매 같은 게임 안 사건과 기본 사용 정보(앱 인스턴스 ID · 기기 모델 · 앱 버전), 앱 비정상 종료 정보를 Google Firebase 애널리틱스로 보내요. 게임을 더 재미있고 공정하게 고치는 데만 써요.
  • 게임 설정 받기: 게임 수치를 Google Firebase 원격 구성에서 받아요. 이때 설치 ID가 쓰여요.
  • 구매(선택): 데이터 팩 · 스타터 팩 · 패스(정기 결제)는 Google Play가 결제를 처리하고, 개발자는 카드 정보를 받지 않아요. 받은 상품은 게임 진행에 저장돼요.
  • 권한: 인터넷과 진동만 써요. 위치 · 연락처 · 카메라 · 마이크 · 실제 폰 알림 내용은 읽지 않아요.
  • 판매 없음: 개인정보를 팔지 않아요.
  • 어린이: 13세 미만을 대상으로 하지 않아요.
  • 바뀔 때: 이 방침이 바뀌면 이 페이지에 시행일과 함께 알려요.
  • 문의: 개발자 소개 페이지

English

Notification Sweeper is a game about swiping phone notifications to merge and pop them. There is no account and no sign-in. Your progress is stored on this phone; data leaves it only for the features below, and only what they need.

  • On your phone: game progress (board, points, data, backup files, GB, apps, premium stars, attendance, achievements, settings) is stored on this phone, and in Google backup if Android device backup is on.
  • Ads: rewarded ads (watched only when you choose) are served by Google AdMob and ad networks connected through AdMob mediation, which process the advertising ID, device information and approximate location (IP) for ads and measurement. Players in the EEA and UK are asked for consent first. See policies.google.com/technologies/partner-sites.
  • Usage analytics: in-game events such as chains, level ups, resets, watched ads, attendance and purchases, with basic usage data (app instance ID, device model, app version) and crash information, are sent to Google Firebase Analytics, used only to make the game more fun and fair.
  • Game settings: game numbers are fetched from Google Firebase Remote Config, which uses an installation ID.
  • Purchases (optional): data packs, the starter pack and passes (subscriptions) are paid through Google Play; the developer never gets card details. What you receive is stored with your progress.
  • Permissions: internet and vibration only. No location, contacts, camera, microphone, and the game never reads your real phone notifications.
  • No selling: personal data is never sold.
  • Children: not directed at children under 13.
  • Changes: any change is posted on this page with its effective date.
  • Contact: developer page

데이터 삭제 · Data deletion

계정이 없으므로 지울 계정 정보도 없어요. 게임 진행은 앱 설정 → 게임 데이터 초기화로 지우거나 앱을 삭제하면 사라져요(기기 백업에 남은 사본은 Android 설정에서 지울 수 있어요). 사용 통계는 Firebase에서 14개월 뒤 자동 삭제되며, 그 전에 지우고 싶으면 개발자 소개 페이지의 연락처로 앱 인스턴스 ID(앱 설정 → 정보)를 보내 주세요. 광고 ID는 Android 설정 → 개인정보 → 광고에서 재설정 · 삭제할 수 있어요.

There is no account to delete. Remove your progress with Settings → Reset game data in the app, or by uninstalling (a copy in device backup can be removed in Android settings). Analytics data is deleted automatically after 14 months; to delete it sooner, send your app instance ID (Settings → About) via the developer page. You can reset or delete your advertising ID in Android Settings → Privacy → Ads.
